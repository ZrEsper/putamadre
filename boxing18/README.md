# Global Melee v18 and Zombie Gore 1.0.8

Bare hands use native skin arms, light punches (8 ticks), right-click heavy punches (18 ticks), a bounded camera-only pitch/roll envelope, and a shared server cooldown. Holding left-click on blocks still mines. Right-click blocks and NPCs retains interaction. Equipped items release the boxing renderer. Heavy hits cost 100 EZWeight stamina, deal 3 base damage and play native world sounds; normal punches retain vanilla damage and the original 60 stamina cost.

The heavy/stomp payload carries only target ID and action. The server checks player state, empty hands, shared cooldown, stamina, actual look ray, collider visibility, target type and range. It schedules network requests on the server thread; forged actions are ignored. The light attack injection gates before the original stamina handler. A short victim tag cancels native upward knockback; confirmed fist hits add horizontal push with no Y impulse.

Gore integration uses an unused synced state bit (30) for four-second knockdowns: 12% on light hits, 30% on heavy hits. Gore .8 treats this as prone collision, refreshes dimensions on client sync, stops jumping/navigation, and clears only this bit at expiry. Permanent leg injuries remain intact. A client-only renderer tail rotates the complete model for temporary falls. Existing Gore melee reactions supply flinch animations.

Right-click a nearby fallen zombie's head to stomp. A native skin leg is rendered in first person and restores model rotations/pose stack afterwards. The server independently checks a short downward ray against the prone head box and colliders. Accepted lethal damage uses player attribution and the existing Gore head-loss state, native red block particles and squish sound. Canceled damage restores the head state rather than forcing death. Gore's original Zombie subclass boundary is preserved; other registered mutant types still receive Global Melee recoil/stun where applicable.

Includes the unshipped v17 fixes: typed vanilla arm fields bypass shadowing GeoBones; an early native hand injection renders and flushes skin arms before cached weapon callbacks; raw clicks and native swing animate punches. Empty hands suppress the old stock proxy, cached TaCZ camera animation and LR delayed lunge. No Epic Fight runtime classes are included. Compile-only API fixtures are excluded from distribution.
