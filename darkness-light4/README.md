# Darkness 4

Conserva la señal de luz del cono Flashlight 6 (alpha 250/255), además del láser (251/255). Solo cambia el shader final; conserva Java, configuración y ciclo de vida del archivo base.

`python darkness-light4/build.py` verifica el archivo base y construye el JAR. `python darkness-light4/test.py` ejecuta 29 comprobaciones reales del shader mediante EGL. No probado dentro de Minecraft.
