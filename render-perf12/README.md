# Render 12: NVG cacheada y orden de capas con coste acotado

Construir: `python render-perf12/build.py`; comprobar: `python render-perf12/test.py`. Reutiliza Java 21 y ECJ/ASM. Inputs fijados por SHA. Las fixtures de NVG se reutilizan de nvg-feedback10 e hybrid-mask8. No hay setup nuevo del entorno.

El perfil WCORUHXPmm contiene exclusivamente Render thread durante 54,94 s. Los porcentajes en spark-report.json se calculan sin contar dos veces llamadas bridge o recursivas. No son porcentajes de servidor, ni uso GPU medido. Iris getFeedbackArcSet ocupa 24,740 % del muestreo y ShaderRegistry.processShaders 15,903 %. La eliminación de framebuffers, 11,419 %, está incluida dentro del coste de NVG: no debe sumarse. El log registra 5980 avisos de InSize del shader híbrido, consistentes con recreación continua. Warborn es el paquete Java de Fracture Point, no otro mod instalado. CorpseRenderer ocupa 6,679 % y las llamadas directas a gibs menos de 1 %; no se eliminan cadáveres, loot ni gore con esa evidencia.

Vision12 usa PostChain propios, una caché LRU de dos modos y resize solo al cambiar dimensiones. Libera al apagar, cambiar jugador/mundo o recargar recursos. El filtro se procesa una vez en AFTER_LEVEL con prioridad LOWEST. No carga ni cierra el postEffect ajeno de GameRenderer. Suspende effectActive mientras NVG está activa y restaura su valor al desactivar, conservando el objeto del efecto de dolor. Conserva el control manual del visor, audio, estática y todos los assets de .11 byte por byte.

GraphOrder12 sustituye opcionalmente el cálculo de feedback arc set de Iris para escenas de más de ocho capas. Conserva categorías y capas, respeta todas las restricciones acíclicas y resuelve ciclos tomando la menor suma de peso entrante. Limita trabajo a 2048 vértices y 32768 aristas por categoría; por encima conserva orden estable. En escenas cíclicas puede cambiar el orden aproximado de transparencias respecto a Iris: revisar armaduras y cuerpos superpuestos. Si el contrato de Iris no existe, vuelve al método nativo. No añade dependencias obligatorias ni cambia los otros hooks de Integration.

Los tests incluyen 2000 frames con una sola creación de filtro, cambio de modo, resize, efectos ajenos, descarga; DAG aleatorios y ciclos ponderados; presupuestos de grafos; verificación ASM de clases nuevas; identidad de assets; audio de N y marcadores de textura. Las fixtures no prueban el runtime Mixin de Minecraft ni los FPS. Es necesaria una nueva captura dentro del juego para cuantificar la mejora.
