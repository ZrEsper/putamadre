# Survivor Creator 29: inglés y alemán según el idioma del juego

Reemplazar Survivor Creator v28 mechanics por `mods/survivorcreator-neoforge-1.21.1-1.0.9-zomboid-v29-en-de.jar` en cliente y servidor. Mantiene los IDs y versión de protocolo del mod. Los ZIPs históricos de servidor siguen conteniendo v28: reemplazar únicamente ese JAR en instalaciones ya extraídas.

Completa el inglés parcial, añade alemán de_de y conserva español es_es y sus variantes latinoamericanas. Otros idiomas usan el fallback inglés habitual de Minecraft. Las traducciones incluyen las 39 ventajas/desventajas y 35 profesiones, sus descripciones, creación/revisión de personaje, habilidades y beneficios, perfiles, selección de zona y el informe de muerte. Usa las claves translatableWithFallback ya existentes para las definiciones sincronizadas por el servidor; no cambia el texto ni los efectos en los JSON de datos.

Los textos escritos directamente en Java se consultan en Language.getInstance() en cada uso. Las recetas de concatenación conservan los argumentos y las cantidades; sus fragmentos de interfaz se traducen en tiempo de ejecución. Los nombres/descripciones de zona conservan las matrices originales y se traducen al leer cada elemento, evitando fijar el idioma durante la inicialización de la clase. Los componentes literales conocidos se convierten a componentes traducibles, con fallback y argumentos, para que el cliente decida su idioma. El texto desconocido y los nombres personalizados se conservan. Los patrones de componentes se compilan una sola vez.

No traduce comentarios de archivos de configuración ni diagnósticos internos del desarrollador; sí traduce errores de perfil visibles. Los textos traducidos generados o almacenados previamente se refrescan al volver a abrir su pantalla o generar el mensaje. No se añaden nuevos mixins ni se modifican los JSON de mixins. El balance, XP, efectos, profesiones, rasgos, spawn y perfiles no se modifican.

Construcción: `python survivor-language-patch/build.py`. Pruebas: `python survivor-language-patch/test.py`. Requiere ECJ 3.39.0 y ASM 9.7.1 preparados en el entorno. Las declaraciones mínimas de Minecraft usadas para compilar NO se incluyen en el JAR. La base enviada y su hash se incluyen para reproducir el resultado.

Validación: claves idénticas entre idiomas, placeholders idénticos y JAR íntegro. 192 comprobaciones ejecutan el helper y métodos de CombatSkillRules/ProfileStore del JAR bajo -Xverify:all con dobles mínimos de Minecraft: cambio español/inglés/alemán, componentes traducibles, textos desconocidos, zonas, plurales, rangos 0–10, valores de daño/recarga/dispersión y nombres personalizados persistidos. ASM verifica 900 métodos. Todos los data JSON y configuraciones de mixins son idénticos a v28. No se ejecutó Minecraft ni se verificó visualmente el ajuste de cada texto alemán en cada resolución.
